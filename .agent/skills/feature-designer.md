SKILL NAME
feature-designer

CATEGORY
product

PURPOSE
Descomponer un PRD en funcionalidades claras y bien definidas.

WHEN TO USE
Después de generar un PRD, para definir las features concretas del sistema.

INPUTS

- PRD
- objetivos del producto

INSTRUCTIONS

1. Analiza el PRD completo.
2. Identifica las funcionalidades principales del sistema.
3. Divide funcionalidades grandes en features manejables.
4. Define comportamiento esperado.
5. Define inputs y outputs de cada feature.

BEST PRACTICES

- Mantener features pequeñas.
- Cada feature debe ser implementable independientemente.
- Priorizar valor para el usuario.

OUTPUT FORMAT

Lista estructurada de features:

Feature Name
Description
User Value
Inputs
Outputs
Dependencies
